## 新发现及修复

| 级别 | 触发条件及问题 | 修复与验证 |
| --- | --- | --- |
| P1 | Go 1.26.10 的 net/http 存在新的可达公告 GO-2026-6859（MaxBytesReader 请求头竞态导致 HTTP/1 服务崩溃），普通及桌面生产标签扫描均失败。 | 将 go.mod 最低工具链升级为修复版本 1.26.11，CI 随之使用该版本；重新运行后端测试、构建及漏洞检查。 |
| P2 | `kubectl get secrets -o json` 返回 SecretList，或工具将 Secret 放入 List、数组及嵌套结果；凭据捕获只识别顶层 Secret，自定义 data/stringData 字段仍可能进入模型上下文。 | 在 JSON 遍历中按每个对象的 kind 保护 Secret。data 解码后捕获，stringData 直接捕获，失败遮蔽；保留 JSON 大整数和普通 ConfigMap 内容。新增回归测试先复现四种遗漏，再验证捕获引用复用及失败路径。 |
| P2 | 仓库路径包含空格或非 ASCII 字符时，CSS 检查直接使用 URL pathname，得到百分号编码的文件路径。 | 使用 Node 的 fileURLToPath 解码文件 URL，同时移除已经具备样式的三项旧白名单。 |
