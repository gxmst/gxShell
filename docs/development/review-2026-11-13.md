# Local review fixes — 2026-11-13

- Passwords, private-key passphrases and migration reads prefer the newest
  encrypted fallback update over an older native value. Failed fallback cleanup
  returns an error and preserves cached data. Regression tests cover restart,
  stale previews, rollback and native-store recovery.
- Transfer, tunnel and named-secret approvals follow the HTTP caller context.
  Cancellation closes pending panels; handlers recheck cancellation before
  starting an operation and after connecting.
- AI approvals include risk tiers, explanations and highlighted spans. Each T3
  plan is reviewed separately, including named-credential use; selective
  approval still maps back to the original plan order.
- Anthropic limits tool count independently of content-block indexes and rejects
  duplicate tool indexes. Gemini retains streamed text and reports truncation
  explicitly while continuing to withhold incomplete tool calls.
- Backup imports validate AI protocol and endpoint settings before import.
  Update feeds must supply HTTPS release URLs without embedded credentials.
  Retry-start errors are credential-protected; unused profile/session identifiers
  were removed from the credential-protection API.
- Frontend hook dependencies are explicit; file/keyboard-interactive events and
  sidebar sizing have dedicated hooks. OS helpers, application icon and transfer
  provider code are separated from shared utilities. Lint has zero warnings.
- Ordinary builds use `scripts/build.ps1`; archived builds reuse it. Binding
  checks verify every exported App method in both JavaScript and TypeScript.
  Go checks enumerate repository packages instead of traversing npm dependencies.
  Local capture reports and extracted media kits are ignored without deleting
  existing marketing files.
